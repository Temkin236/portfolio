# Temkin's World — Frontend

Modern, high-performance personal portfolio and digital identity platform built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

## Tech Stack
- **Framework**: React 19 (SPA with React Router DOM v7)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4 & custom lilac/lavender luxury design tokens
- **Animations**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React & Custom SVG Atoms

## Development
```bash
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
